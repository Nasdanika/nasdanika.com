Below are AI interaction surfaces:

  • JSON Schema - generated from metamodels and models
  • JSON - JSON constrained by JSON Schema is generated from model data
  • *Tools - tool definitions are generated from metamodel documentation - the same documentation which is provided to humans. Tool calls are routed to model operations.
