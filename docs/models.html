Models

Tower floors and aspect models

  • nxcore — Nasdanika Core Metamodel in Xcore: the base floor. Documentation as structure, time including relative time, provenance markers.
  • role — Undergoer / Role / Actor metamodel for ownership and responsibilities.
  • multiple-criteria-decision-analysis (site) — MCDA and AHP: alternatives, criteria, experts; the decision floor.
  • risk — risk management domain and agentic risk management.
  • rules — rules, rule sets, inspectors, violations, waivers.
  • architecture (site) — architecture elements and relationships; being replaced in place by the lightweight tower version.
  • accounting — model/file based double-entry accounting; tower balcony demo.
  • enterprise (site) — semantic enterprise model from the Beyond Diagrams book; dissolving into product management, architecture, and catalogs.

Enterprise, product, and organization

  • capability — capability model; root of the pull stack.
  • product-management (site) — personas, concerns, capabilities, evidence: pull, not push.
  • product-management-ref — earlier reference product management model.
  • org-design (site) — organizational design: structure, strategy, capabilities, coordination.
  • party — party, organization, role, contact method.
  • process — processes with activities, roles, actors, resources, artifacts.
  • roadmap — parties, phases, deliverables.
  • goals — goal, objective, key result, task, increment.
  • togaf — TOGAF 10 concepts: study, reference, architecture-as-code.
  • c4 — Ecore C4 model.
  • uaf — Unified Architecture Framework model.

AI and agents

  • agent (site) — agentic AI systems: agents, tasks, tools, skills, examples, language models.
  • agent-skills — agent skills model.
  • a2a — agent-to-agent model generated from the A2A JSON schema.
  • crew-ai — CrewAI agents, tools, crews: education, semantic mapping, code generation.
  • semantic-kernel — Semantic Kernel concepts; declarative kernel construction.
  • semantic-context — bidirectional projections between source and target models; scoped views for agents.
  • reasoning — forward reasoning on Ecore classes using compute graphs.
  • azure-document-intelligence — model and loader for Azure Document Intelligence.
  • smart-home — rooms-and-lights demo for agentic solutions.
